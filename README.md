# 가계부

고정지출과 생활지출을 분리해서 보여주는 개인 가계부 웹앱.
iPhone 13 mini 세로 화면(375 × 812)에 맞춘 단일 페이지 앱이며, 데이터는 브라우저의 localStorage에만 저장된다.

## 핵심 아이디어

지출을 세 가지로 나눈다.

| 버킷 | 성격 | 예시 |
|---|---|---|
| **고정지출** | 이번 달에 바꿀 수 없는 돈 | 대출, 보험, 관리비, 통신비 |
| **생활지출** | 오늘 내가 결정하는 돈 | 식비, 카페, 교통, 미용 |
| **대납 (정산예정)** | 내 돈이 아님. 돌려받을 돈 | 출장비 |

대출·보험이 식비와 같은 통계에 섞이면 "이번 달 얼마 썼다"는 숫자만 남고 정작 조절할 수 있는 돈이 묻힌다.
그래서 홈의 큰 숫자는 **생활지출 하나만** 두고, 고정지출은 그 아래 작은 글씨로 붙인다.

통계 탭에는 이 개념을 그대로 옮긴 **"진짜 여윳돈"** 표가 있다.

```
이번 달 수입
− 고정지출        (이미 결정된 돈)
─────────────
쓸 수 있었던 돈
− 실제 쓴 돈
─────────────
남은 여유          ← 이게 성적표
```

### 입력 부담 줄이기

내역을 넣을 때마다 고정/생활을 고르는 건 번거롭다. 그래서 두 곳에 기본값을 둔다.

1. **자산 그룹**의 기본 구분 — 「대출 보험」 그룹에서 지출하면 자동으로 고정
2. **분류**의 기본 구분 — '식비'를 고르면 자동으로 생활

대부분 자동으로 맞고, 예외일 때만 토글을 누르면 된다.

### 지출에 미표기

출장비처럼 내 카드로 먼저 결제하고 나중에 정산받는 돈은 "지출에 미표기"를 켠다.
목록에는 검은색으로 남지만 지출 합계·통계에서는 빠지고, 잔액에서만 실제로 차감된다.
해당 자산을 **미수금** 종류로 두면 자산 집계표에서 "받을 돈"으로 따로 잡힌다.

## 화면

- **홈** — 총 잔액, 이번 달 수입/지출/잔액, 수입 대비 지출 비율, 하루에 쓸 수 있는 돈, 자산 그리드(5열)
- **자산** — 그룹별 집계표(자산 / 부채 / 합계) → 자산 상세(일별 · 월별 · 연별, 누적잔액, 분류별 아코디언)
- **통계** — 생활 / 고정 / 전체 분리, 전월 대비, 진짜 여윳돈, 분류별 막대
- **설정** — 자산·분류 관리, 메인자산, 월 시작일, 테마, 백업/복원, CSV 내보내기

## 회계 월 시작일

월 시작일을 25일로 두면 `6/25 ~ 7/24` 가 **7월**이 된다. 급여일에 맞춰 한 달을 끊기 위한 것으로,
홈·자산·통계의 모든 집계가 이 기준을 따른다. 설정에서 1~28일 중 고를 수 있다.

## 실행

정적 파일이라 서버가 없어도 `index.html`을 열면 동작한다. 로컬 서버로 띄우려면:

```bash
python -m http.server 8765
```

아이폰에서는 Safari로 열고 공유 → "홈 화면에 추가"를 하면 주소창 없이 앱처럼 실행된다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 셸, 탭바, 모달 루트 |
| `style.css` | 디자인 토큰(라이트/다크), 컴포넌트 |
| `core.js` | 상태·저장, 회계월 계산, 잔액 집계, 포맷 |
| `views.js` | 홈 / 자산 / 자산상세 / 통계 렌더링 |
| `settings.js` | 설정 및 하위 관리 화면 |
| `modals.js` | 내역·자산·그룹·분류 편집 시트 |
| `app.js` | 라우팅, 액션 테이블, 이벤트 위임, 백업 |

의존성 없는 바닐라 JS. 빌드 단계가 없다.

## 데이터

- 전부 브라우저 `localStorage`(`ledger.v1` 키)에 저장된다. 서버로 나가지 않는다.
- **기기를 바꾸기 전에 설정 → 백업 내보내기로 JSON을 받아두어야 한다.** 브라우저 데이터를 지우면 함께 사라진다.
- 처음 실행하면 데모용 샘플 내역이 들어 있다. 설정 → "샘플 내역 전체 삭제"로 비우면 자산과 분류는 남고 내역만 지워진다.
- 샘플의 자산 이름과 금액은 임의의 예시다. 설정 → 자산 관리에서 실제 이름과 시작잔액으로 바꿔 쓰면 된다.
